# Reklamy v2

Čtyři obrázky (A a B, 1080x1350 a 1080x1920) generované z HTML šablony: `node design/reklamy-v2/build.mjs` z kořene repa (potřebuje Chrome, fonty z `web/public/fonts`, čísla z `data/etf.json`).

Oproti první verzi (`design/reklamy`): upozornění na riziko přímo v obrázku, celá skladba v bezpečné zóně (9:16 mimo horních 250 px a dolních 350 px), místo falešného tlačítka řádek textu se šipkou, poznámka o zdroji a datu ověření, v B ukázané řádky VOO a IVV (ne jen ten s největším rozdílem). Hotové kopie jsou v `ads/`.
